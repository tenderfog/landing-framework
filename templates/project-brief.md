# Project brief — заповнити для конкретної акції

Для нової campaign landing обов'язковий [stack Vue 3 + Nuxt 4](../docs/00-technical-stack.md): Vue SFC, Composition API, `<script setup lang="ts">`. Static generated deployment — default; SSR потребує погодженого hosting contract. Технічні версії/build фіксуються один раз в integration contract; цей brief зберігає бізнес-рішення та посилання на нього.

Детальні state/CTA rows заповнюються в state matrix, без другої копії тут. Для кожного застосовного guest, unverified, available, exhausted, error та ended сценарію описати user story. Вказати, що показує UI та який server факт дозволяє participation. Перелік невідомих: питання → owner → потрібний доказ → незалежна робота, яка може тривати.
